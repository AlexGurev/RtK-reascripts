# Reach the Knob — REAPER Scripts

A collection of Lua scripts and tools for **REAPER**, created by Alex Gurev of **Reach the Knob**.
Scripts can be installed individually or via [ReaPack](https://reapack.com).

## Installation

### Via ReaPack
1. Open REAPER → Extensions → ReaPack → Import repository.
2. Paste the repository URL: https://raw.githubusercontent.com/AlexGurev/RtK-reascripts/refs/heads/main/index.xml
3. Refresh packages and install the scripts you want.

### Manual Installation
1. Download the `.lua` files from this repository.
2. Place them in your REAPER scripts folder.
3. Refresh REAPER actions list.
